# ساخت APK فقط با گوشی

این پروژه برای ساخت APK با GitHub Actions آماده شده است.

## مراحل
1. در گوشی وارد GitHub شوید و یک حساب رایگان بسازید یا وارد حساب خود شوید.
2. یک Repository جدید بسازید؛ مثلاً `HesabYar-Labaniyat`.
3. محتوای این پوشه را داخل Repository آپلود کنید (فایل ZIP را مستقیم داخل Repository نگذارید؛ ابتدا Extract کنید، یا فایل‌ها را با گزینه Upload files آپلود کنید).
4. بعد از آپلود، از تب **Actions** وارد workflow با نام **Build APK** شوید.
5. اگر workflow خودکار شروع نشد، **Run workflow** را بزنید.
6. بعد از سبز شدن اجرای workflow، روی اجرای آن بزنید.
7. در بخش **Artifacts** فایل `HesabYar-Labaniyat-APK` را دانلود کنید.
8. ZIP دانلودشده را باز کنید؛ داخل آن `app-debug.apk` است.
9. APK را روی گوشی نصب کنید. اگر اندروید اجازه خواست، اجازه نصب از همان مرورگر/فایل‌منیجر را فعال کنید.

## نکته
این نسخه برای تست است و APK با امضای debug ساخته می‌شود. برای انتشار در Google Play یا نصب حرفه‌ای با امضای شخصی، بعداً release signing اضافه می‌کنیم.
